# personal-ai-email-agent
AI-powered personal Gmail assistant with internship detection, job alerts and voice notifications.
Personal AI Email Agent 🚀

An intelligent personal email assistant that automatically analyzes Gmail messages, identifies important opportunities, filters unwanted promotions, and delivers smart notifications with English voice announcements.

🎯 Project Vision

Never miss an internship, job opportunity, interview invitation, or important college email again.

✨ Features

- Gmail OAuth 2.0 integration
- Automatic email classification
- Internship opportunity detection
- Full-time and part-time job detection
- Interview invitation alerts
- College and education updates
- Freelance opportunity detection
- Spam and advertisement identification
- AI-powered email summaries
- English voice notifications
- Android application
- Web dashboard
- Custom MCP server
- Daily email intelligence reports

🛠️ Technology Stack

Component| Technology
Backend| Python
API| FastAPI
Email| Gmail API
Authentication| Google OAuth 2.0
AI| Local LLM / Python classifier
Database| SQLite / PostgreSQL
MCP| Python MCP SDK
Android| Kotlin
Notifications| Firebase Cloud Messaging
Dashboard| HTML, CSS, JavaScript

📂 Project Categories

1. Internship
2. Jobs
3. Interviews
4. College
5. Freelance
6. Spam & Advertisements

🔐 Privacy & Security

- OAuth-based Gmail authentication.
- Minimum required Gmail permissions.
- No automatic email deletion.
- No automatic email sending.
- Secure credential storage.
- User-controlled notifications.

🚀 Installation

git clone YOUR_GITHUB_REPOSITORY_URL
cd personal-ai-email-agent

python -m venv .venv
pip install -r requirements.txt

uvicorn agent.main:app --reload
